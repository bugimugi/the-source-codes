# Design mockups (reference only, local only)

**These images are NOT committed to Git** (see `.gitignore`): the repository is public and the full designs
should not be visible before launch. Copy the files into this folder on your own computer; nothing is uploaded.

Put the finished design images here, one file per page or section, in order (copy them in with the Explorer):

    01-startseite.png
    02-wissensmatrix.png
    03-organe.png
    04-orte.png
    05-frequenzlabor.png
    ...

Rules
- Highest resolution available (at least 1920 px wide). Full-size originals, not chat screenshots.
- PNG, JPG or WebP.
- Only images you own, generated yourself, or that are licensed for this use.
- These files are design references. They are not shipped on the website; finished, optimised
  pieces are cut out of them into `public/assets/`.
- Numbers, stamps or "verified" labels inside a mockup are placeholders and are not copied. Real
  values come from `content/`.
